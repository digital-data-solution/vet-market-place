# Background music tracks

Drop real, licensed royalty-free tracks here (`.mp3`, `.wav`, `.m4a`, `.aac`, or `.ogg`) and
`listingVideo.service.js` will automatically pick one at random for every rendered video.
Empty folder = renders stay silent — no fake placeholder audio ships from this repo.

**Where to get tracks:**
- **No signup needed:** YouTube Audio Library (studio.youtube.com → Audio Library) — free,
  most tracks need no attribution.
- **Via API:** Jamendo (https://devportal.jamendo.com/) — free developer account, gives you
  a `client_id`. All tracks are Creative Commons, but the specific license varies — check
  each track allows commercial use before using it here.

Aim for ~5 tracks, upbeat/friendly mood matching a pet & animal marketplace — nothing that
overpowers the on-screen text.
